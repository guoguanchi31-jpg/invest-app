## 兼容与回退

- 本轮不增加 schema 版本，不改写已应用的 schema 10/11；数据库仍为 schema 11，
  家庭备份仍为 v8，更正审计仍为 v1。
- 新增读取字段保持兼容，旧账户权限和金额字段不变。新版前端看到缺少诊断信息的
  未应用流水会要求核对，不自行判断为合法补录。
- 更正使用原流水引用、预期余额、预期应用标记、原因和稳定幂等键；事务失败不留下
  余额、标记、审计、快照或命令结果的半成品。
- 已被旧恢复流程封装为 historical 的审计只保留原文，本轮不猜测或重写其 ID。
- 代码回退应保留 v1/v2 操作存储兼容层和 schema 11，不清理未知键或服务端墓碑。
  如回退到旧协议代码，先停止写入并按升级说明保存数据库及命令状态。
- 不将“更正”当成可随意反向执行的按钮。若持有人发现更正依据错误，应结合审计和
  原始对账单重新诊断；不得手工翻转标记、重复追加调整或自动重算。

## 账本持有人仍需确认

真实账本是否存在历史漏扣、是否曾经人工补偿、负债/投资现金方向是否与对账单
一致，以及更正后的余额是否真实。代码修复不替代这些事实核实。
从“账本 → 账本诊断”逐笔处理；期初不足或其他差额另行核对。

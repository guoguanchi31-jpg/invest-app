# 前端视觉与交互规范

## 本轮根因

- 旧界面以暖米色、深绿和金色为主，页面背景、卡片、控件和提示块缺少明度分层。
- 多轮响应式规则同时改写交易行；窄卡片把日期推到独立第二行，日期字号又被通用
  `.transaction time` 规则放大，形成类似输入框的视觉块。
- 16-28px 圆角和大面积阴影被用于普通信息区，页面显得卡片化且缺少操作密度。
- 标题在移动端跳到 32px，和 10-12px 的业务数据标签形成过大的排版断层。
- 悬停、按压、键盘焦点及减少动态效果没有统一的状态契约。

## 设计基础

颜色定义集中在 `frontend/src/index.css` 的 `:root`：

| 语义 | 变量 | 值 |
| --- | --- | --- |
| 主操作 | `--green` | `#176b4d` |
| 主操作悬停 | `--green-2` | `#0f5138` |
| 辅助强调 | `--gold` | `#b77a22` |
| 页面背景 | `--paper` | `#f4f6f5` |
| 信息面 | `--panel` | `#ffffff` |
| 主文字 | `--ink` | `#17211d` |
| 次文字 | `--muted` | `#62706a` |
| 分隔与弱底色 | `--line` / `--soft` | `#dce3e0` / `#edf1ef` |
| 正向 / 负向 | `--positive` / `--danger` | `#147a52` / `#c5483d` |

规范：

- 金额使用等宽数字；正负值只使用对应语义色，不以图形高度截断负值。
- 页面标题使用系统无衬线字体，桌面 22px、手机 26px；面板标题 16px。
- 页面面板圆角 12px，控件圆角 8px；胶囊形仅用于状态、分段选择和进度。
- 普通面板使用 1px 边框和一级阴影；只有弹窗、悬浮菜单和主操作使用更高层阴影。
- 间距以 4px 为基础，常用组合为 8、12、16、24px。

## 内容质量

- 所有动态标签进入展示层前必须经过 `displayContent` 规范化。
- 过滤空白、`null`、`undefined` 和 `NaN` 哨兵文本，但保留合法的 0 和负数。
- 组合标签只拼接有效片段；必要字段缺失时使用明确业务回退文案。
- 图表分类必须具备有效名称、正数金额和正数占比，否则不得渲染。
- 不展示重复解释界面自身行为的静态提示；仅保留影响核算理解或可执行决策的信息。

## 信息层级

- 总览指标是同级重复项，可使用卡片；页面章节不包成额外浮层。
- 资产所属人分组是章节容器，不再作为卡片；账户本身仍是可点击的业务对象。
- 最近交易使用两列：左侧图标、名称和账户，右侧金额、日期和编辑操作。
  总览与账本统一使用“主信息 + 分类日期 + 金额尾部”结构，整行承担编辑交互，
  不重复展示独立编辑按钮。
- 总览预算卡由 `dashboard-budget` 容器查询负责；进度说明固定为左右两列，
  被动状态标签不继承 44px 触控尺寸，超支进度统一使用负向语义色。
- 持仓明细由 `holdings-panel` 容器查询负责：桌面保留九列表格，窄面板合并标的与
  账户、市值和收益率为单行摘要；点击整行打开底部详情抽屉查看完整指标和交易
  操作。筛选与新增操作必须保持同组且不溢出。
- 账本筛选结果使用“范围 + 收入 / 支出 / 结余”紧凑信息条；普通流水整行作为
  编辑入口，金额和尾部状态共用一列。核算例外说明必须保留，不以密度为由隐藏。
- 投资大类配置使用环形图表达占比，环内显示百分比，中心显示总市值，完整图例
  同时展示分类、金额和占比；买卖记录的计数、说明和账户筛选归入同一标题区。
- 三项状态切换必须使用固定三等分分段控件，状态名称与计数徽标分层展示，
  不允许沿用两列断点导致第三项换行。
- 单项筛选器使用内嵌字段标签：48px 控件高度、13px 选中值、8px 圆角，
  hover 提升边框对比，focus 使用统一主色焦点环；窄屏自动扩展为全宽。
- 工具栏按主操作靠左、高频优先排列；手机端同组命令等宽且单行可达。

## 交互状态

- 所有按钮、输入框和可点击业务对象共享 140ms 状态过渡。
- 主按钮悬停使用 `--green-2`；按下仅下移 1px，不缩放布局。
- 键盘焦点使用 2px 主色轮廓和 `--focus-ring`，不能只依赖颜色变化。
- 页面内容使用 200ms、4px 位移的轻量入场；`prefers-reduced-motion: reduce`
  下动画和过渡立即结束。
- 图标按钮使用 Lucide 图标，并保留 `aria-label` 与 `title`。
- 详情抽屉必须支持点击背景和 Escape 关闭；关闭后焦点返回原列表行。

## 响应式所有权

- `760px` 是壳层唯一导航断点：以上使用左侧导航，以下使用底部导航和悬浮记账按钮。
- 表格与业务列表的收缩由对应容器查询拥有；不得在视口媒体查询中改写
  `ledger-row`、信用账户表或预算表布局。
- 手机摘要默认两列，奇数末项跨两列；低于 340px 才降为单列。
- 粗指针环境的核心控件最小触控尺寸为 44px。
- 页面必须在 320、390、560、834、1440px 下无横向溢出。

## 回归要求

- `responsiveCss.test.js` 检查变量、断点所有权、焦点和减少动态效果契约。
- `app-smoke.spec.js` 检查交易行不重叠、行高不超过 72px、日期不带边框或背景、
  日期字号不超过 11px，以及移动端编辑按钮达到 44px；同时检查预算说明分离、
  状态标签高度、进度条语义、持仓列表密度、环形图标签，以及账本摘要和流水行高。
- 视觉改动后必须运行 `npm run lint`、`npm test`、`npm run build` 和
  `npm run test:e2e`，并检查桌面、平板、手机稳定态截图。
